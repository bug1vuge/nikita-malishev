# Правила разработки

Одностраничник на React 19 + TypeScript + Vite с пререндером HTML. Как запустить и настроить сайт — в README.md.

## Команды

- `npm run dev` — разработка
- `npm run build` — проверка типов, сборка, пререндер в `dist/`
- `npm run validate` — валидация HTML (html-validate); перед пушем должна проходить
- Сборка под GitHub Pages: `BASE_PATH=/nikita-malishev/ VITE_DEMO=1 VITE_NOINDEX=1 npm run build`

## Где что лежит

- Весь текст сайта (заголовки и подводки секций, описания, FAQ), контакты, фото и SEO —
  только в `src/content.ts`. В компонентах остаются лишь короткие подписи интерфейса
  (поля формы, кнопки, aria-label). Заглушки помечены `ЗАГЛУШКА`.
- Секции — `src/components/*` (у каждой свой CSS рядом).
- Валидация заявки общая для клиента и сервера — `src/lib/validation.ts`.
  Меняешь правила — синхронно поправь `public/lead.php`.
- Пути к файлам из `public/` в коде пиши через `import.meta.env.BASE_URL`, не через `/`:
  на GitHub Pages сайт живёт в подпапке.

## Правила

- Токен Telegram-бота никогда не попадает во фронтенд и в репозиторий.
- Анимации уважают `prefers-reduced-motion` и останавливаются вне экрана.
- Появление при скролле отмечается атрибутом `data-in`, не классом: React
  перезаписывает `className` при ререндере.
- Проверяй вёрстку на 320, 360, 390, 820 и 1440 px; горизонтальной прокрутки быть не должно.

## Коммиты

Conventional Commits, на английском, в повелительном наклонении, без точки в конце:

```
<type>(<scope>): <summary до 72 символов>

<тело при необходимости: что и почему>
```

- Типы: `feat`, `fix`, `perf`, `style`, `refactor`, `docs`, `chore`, `ci`, `test`, `build`.
- Scope — секция или модуль: `hero`, `formats`, `booking`, `seo`, `api`, `ci`…
- Работу дроби на логические коммиты (каркас, секции, форма, SEO, CI, правки),
  каждый коммит должен собираться (`npm run build`).
- Правки по ревью — отдельными `fix`/`style`/`perf`-коммитами, а не одним общим.
