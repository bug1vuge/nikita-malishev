# Сайт ведущего Никиты Малышева

Одностраничный сайт на **React 19 + TypeScript + Vite**. HTML пререндерится при сборке (весь текст виден поисковикам сразу), форма заявки отправляет данные в **Telegram** через серверную функцию — токен бота не попадает в браузер.

## Быстрый старт

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # проверка типов → сборка → пререндер в /dist
npm run validate   # проверка валидности HTML
npm run preview    # посмотреть собранную версию
```

Нужен Node.js 20+.

## Где менять тексты, фото и контакты

Всё наполнение — в одном файле: **`src/content.ts`**. Данные взяты из профиля Никиты на Горько: описание, пакеты и цены, места в конкурсах, фрагменты отзывов.

Места с пометкой `ЗАГЛУШКА` нужно заполнить:

| Что | Где в `content.ts` |
|---|---|
| Телефон, WhatsApp, Telegram, Instagram, ВК (на Горько скрыты) | `contacts` — пустое поле не показывается на сайте |
| Домен сайта | переменная `VITE_SITE_URL` в `.env` |

Пока контактов нет, связь идёт через форму заявки и ссылку на профиль на Горько.

## Фото

У каждого фото в `src/content.ts` свой источник: `gorko` — фото из профиля на Горько (подгружается с их CDN в нужном размере), `widths` — своё фото из `public/img/`.

Чтобы перейти на свои фото:

1. Положите исходник в `photos-src/` (папка не попадает в git), например `photos-src/hero.jpg`.
2. Пропишите ширины в `scripts/optimize-images.mjs` и запустите `npm run images` — появятся AVIF + WebP в `public/img/`.
3. В `src/content.ts` у этого фото замените `gorko` на `widths` с теми же ширинами и укажите пропорции `ratio`.

Картинки грузятся лениво, с `srcset`/`sizes`, фиксированными пропорциями (нулевой сдвиг вёрстки) и аккуратной заглушкой, если файл недоступен.

## Форма → Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Напишите боту любое сообщение и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — возьмите `chat.id`.
3. Подключите один из вариантов:

**Vercel (рекомендуется).** Функция уже лежит в `api/lead.ts`. В настройках проекта добавьте переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Build command: `npm run build`, output: `dist`.

**Обычный PHP-хостинг.** В `.env` укажите `VITE_LEAD_ENDPOINT=/lead.php`, соберите проект и загрузите содержимое `dist/` в корень сайта. Токен положите в `lead-config.php` уровнем выше корня сайта:

```php
<?php return ['token' => '123456:ABC...', 'chat_id' => '123456789'];
```

Обрабатываются: проверка полей на клиенте и на сервере, маска телефона, таймаут, нет интернета, ошибка сервера, сбой Telegram, лимит заявок с одного IP, ловушка для спам-ботов и сохранение черновика.

## GitHub Pages (демо)

Workflow `.github/workflows/deploy.yml` собирает и публикует сайт при каждом пуше в `main`. Один раз включите в репозитории **Settings → Pages → Source: GitHub Actions**.

На Pages сайт работает в демо-режиме: форма показывает успешную отправку, но никуда не шлёт, а страница закрыта от поисковиков. Для боевого запуска подключите репозиторий к Vercel или уберите `VITE_DEMO` и `VITE_NOINDEX` из workflow и укажите `VITE_LEAD_ENDPOINT`.

## Что внутри

- **Первый экран:** сцена в свете прожектора — луч из-под потолка ведёт пятно света за курсором, пылинки вспыхивают в луче, имя раскаляется там, куда падает свет. На телефоне свет сам медленно скользит по сцене.
- **Пакеты и цены** в виде билетов; кнопка «Выбрать пакет» подставляет пакет в заявку.
- **Анимации:** появление блоков при скролле, параллакс, плавающее превью фото в списке форматов, линия-прогресс в шагах работы, конфетти после отправки заявки. Всё отключается при «уменьшить движение» и останавливается вне экрана.
- **Форма:** свой календарь, выпадающий список и счётчик гостей с управлением с клавиатуры.
- **Адаптив:** телефон (от 320 px), планшет, десктоп.
- **SEO:** пререндер HTML, title/description, Open Graph, микроразметка `Person`, `ProfessionalService` с отзывами и `FAQPage`, `sitemap.xml`, `robots.txt`.
- **Валидность и доступность:** html-validate без ошибок, навигация с клавиатуры, видимый фокус.

## Структура

```
src/
  content.ts            ← все тексты, контакты, фото, цены, SEO
  components/           ← секции страницы (каждая со своим CSS)
  lib/spotlight.ts      ← прожектор на первом экране
  lib/motion.ts         ← появление при скролле, параллакс, конфетти
  lib/validation.ts     ← общая валидация заявки (клиент + сервер)
  lib/sendLead.ts       ← отправка формы и обработка ошибок
  entry-server.tsx      ← пререндер и мета-теги
api/lead.ts             ← серверная функция для Vercel
public/lead.php         ← то же для PHP-хостинга
public/privacy.html     ← политика конфиденциальности (шаблон — заполните реквизиты)
scripts/                ← пререндер и оптимизация фото
```
